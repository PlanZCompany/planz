# 03-shadcn-setup.md

## Goal

Install and configure the latest shadcn/ui in the current Next.js project.

## Tasks

1. Initialize shadcn/ui
2. Ensure Tailwind setup is correct
3. Add `cn` utility and base config
4. Install base UI dependencies
5. Add first base components:
   - button
   - input
   - textarea
   - select
   - card
   - dialog
   - badge
6. Keep Payload working
7. Do not build admin screens yet

## Expected result

- shadcn/ui is installed and working
- base components can be imported
- project still runs normally

## Definition of done

- shadcn init completed
- base components added
- app starts without errors
- Payload admin still works
